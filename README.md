This repository is developed based on the WiLoR codebase. The **original renderer (only Ubuntu)** has been replaced with **Open3D-based renderer(Ubuntu & Windows)**.

![](./assets/img/hand_viz.gif)

The main features include:

1. **MANO model visualization**: aligned coordinate systems.
3. **Voxel-based grasp region estimation**: Construction of voxel blocks to estimate potential hand grasp regions, with outputs visualized as a heatmap.
